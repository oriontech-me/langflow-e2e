# Spec: Playground Output – Structured Data

**Test file:** `tests/tests-automations/regression/core-functionality/playground/playground-output-data.spec.ts`

## What this test validates

Verifies that the Playground correctly renders structured data outputs generated by the Mock Data component:

1. `data_output` (type `JSON`) is serialized via `_serialize_data` and displayed as a JSON code block (`\`\`\`json`) in the chat.
2. `dataframe_output` (type `Table`) is serialized via `df.to_markdown(index=False)` and displayed as a Markdown table in the chat.

## Tags

| Test | Tags |
|---|---|
| JSON Data output as code block | `@release` `@regression` `@playground` _(`@stable` removed — tracked in [#120](https://github.com/oriontech-me/langflow-e2e/issues/120))_ |
| DataFrame output as Markdown table | `@stable` `@release` `@regression` `@playground` |

## Validation criterion

| Test | Criterion |
|---|---|
| JSON Data output as code block | Chat message contains a `<code>` element and the text includes `"records"` (root key of the serialized JSON) |
| DataFrame output as Markdown table | Chat message contains a `<table>` element rendered by react-markdown with remarkGfm |

## External dependencies

None. The tests use the native Langflow **Mock Data** component — no API key or LLM is required.
