# Playground Output — Structured Data

**Last validated:** Langflow 1.10.x

---

## What this test validates *(required)*

Verifies that the Playground correctly renders structured data outputs generated by the Mock Data component:

1. `data_output` (type `JSON`) is serialized via `_serialize_data` and displayed as a JSON code block (` ```json `) in the chat.
2. `dataframe_output` (type `Table`) is serialized via `df.to_markdown(index=False)` and displayed as a Markdown table in the chat.

Both tests run without user input and without an API key or LLM — the Mock Data component produces the output directly.

---

## Tags *(required)*

`@stable` `@release` `@regression` `@playground`

---

## Step by step *(required)*

**Test 1 — JSON Data output as code block**

1. Delete existing flows and create a flow with the Mock Data component connected to ChatOutput
2. Run the flow without user input via `runNoInputFlow`
3. Wait for the first message to appear in the Playground
4. Assert the chat message contains a `<code>` element with text including `"records"` (root key of the serialized JSON)

**Test 2 — DataFrame output as Markdown table**

1. Delete existing flows and create a flow with the Mock Data component (dataframe output) connected to ChatOutput
2. Run the flow without user input via `runNoInputFlow`
3. Wait for the first message to appear in the Playground
4. Assert the chat message contains a `<table>` element rendered by react-markdown with remarkGfm

---

## Validation criterion *(required)*

- JSON test: chat message contains a `<code>` element and its text includes `"records"` (root key of the serialized JSON)
- DataFrame test: chat message contains a `<table>` element rendered by react-markdown with remarkGfm

---

## External dependencies *(required)*

- `src/backend/base/langflow/components/data/` — Mock Data component; changes to serialization logic (`_serialize_data` or `df.to_markdown`) would alter the rendered output format
- `src/frontend/src/components/core/chatComponents/` — Markdown and code block rendering in the Playground chat; changes to react-markdown plugins or code block CSS classes would break the assertions

---

## Preconditions *(optional)*

- Langflow running and accessible at `PLAYWRIGHT_BASE_URL`
- No API key or LLM required — tests use the native Mock Data component
